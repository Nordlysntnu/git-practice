This repository contains a menu for the Nordlyskiosken. Your task is to update the prices and names of the items in the menu and create a new file with the nighttime prices for the kiosk, while separating the development into different branches. You may freely choose which git tool you use (command line, VS code, github desktop) and you will try to solve the problem with your chosen tool. The tasks are as follow

# Task 1

Due to increasing food prices, we also have to increase the prices of our items. Go into the branch called ```price-change``` and edit menu.txt by raising each price by 3kr. Make sure to save and commit your changes.

# Task 2

Due to customer demand, we are changing our chichicken ramen to be a beef ramen, which will be priced the same as the chicken ramen. Go into the branch called ```item-change``` and change Chicken Ramen to Beef Ramen. Make sure to save and commit your changes.

# Task 3

We now have to actually update our menu with all of our changes. Go back into the ```main``` branch and merge the ```price-change``` and ```item-change``` branches into. Does this cause a problem? If so, resolve the problem.

# Task 4

Nordlyskiosken is making a new night menu. Go into the ```night-menu``` branch, create a new file, ```night_menu.txt```, in which all of the prices are 80kr. Then merge this into the main branch again.
